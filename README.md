This data and code was used to answer the following research questions: 
Aim one: Is rural residence associated with flu vaccination status?
Aim two: Does transportation access moderate the relationship between rural residence and flu vaccination status? 
Aim three: Does disability status moderate the relationship between rural residence and flu vaccination status?
Data utilized was from the 2024 Medicare Beneficiaries survey. The data was joined from the different surveys collected that year. 
The necessary variables for analysis were selected to make the dataset more readable. That final data file is included in this repository. 
Three binary logistic regression models were created to address these three research questions.
